The person wants to see the room on the web.

1. Call the `floor_link` tool.
2. Give them the URL it returns **verbatim, on its own line** — it is long and a

3. Say in one sentence what it does: it connects a GitHub account to this
   terminal so the browser is the same person, rather than signing them up
   again. Do not describe it as creating an account.

If they are already connected, the tool says so and gives the room's address —
just pass that on.

Do not run any other tools while doing this.
